# Student-Performance-Analysis-using-R
This project studies how students perform in exams using R. It uses data analysis and graphs to find patterns, compare scores, and understand what factors affect student results.  Built with: R, ggplot2, dplyr, tidyr
This project analyzes student performance using R programming.
It uses statistics and data visualization to study how different factors (like study time, attendance, and scores) affect academic results.

Tools Used:

R Language

Packages: ggplot2, dplyr, tidyr, psych

 Features:
Data cleaning and preparation

Statistical analysis and summaries

Graphs and visual reports using ggplot2

Identify key factors affecting performance

Objective:

To understand student performance patterns and improve learning through data-driven insights.



How to Run:

Open project in RStudio

Install required packages:

install.packages(c("ggplot2", "dplyr", "tidyr", "psych"))


Run the file Student_Performance_Analysis.R

📈 Result

The project shows visual charts and analysis of student marks, helping understand trends and factors behind performance differences.
